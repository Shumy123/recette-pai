# Recettes PAI

Idées de recettes sans allergènes (PAI) pour le panier repas et le goûter.
Appli web installable (PWA), hébergée sur GitHub Pages, données dans Firebase (connexion Google + Firestore).

- `index.html` est généré depuis la version Claude par `build_pwa.py` : ne pas le modifier à la main.
- `photos/` : photos des plats (Wikimedia Commons, licences libres, crédit affiché sur chaque fiche).
- `firestore.rules` : seules les adresses du foyer ont accès aux données.
